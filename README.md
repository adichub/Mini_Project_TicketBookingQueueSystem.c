# Ticket Booking Queue System

A console program in C that manages ticket bookings using a circular queue (size 5).

## Features
- Book a ticket with an ID
- Process the oldest ticket
- Display, search and delete tickets
- Exit

## How to compile and run
gcc -Wall Mini_Project_TicketBookingQueueSystem.c -o ticket_queue
./ticket_queue

On Windows, run ticket_queue.exe instead of ./ticket_queue.
